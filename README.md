# IT Support Ticket Management System

A web-based IT Support Ticket Management System built with HTML, CSS, and JavaScript. The application allows users to submit, manage, track, and organise IT support requests through a simple dashboard.

## Features

- **Create Tickets:** Submit support requests with employee details, issue title, category, description, and priority.
- **Unique Ticket IDs:** Automatically generate a unique ID for every ticket.
- **Ticket Management:** Edit and delete existing tickets.
- **Status Tracking:** Update tickets between Open, In Progress, and Resolved.
- **Dashboard Statistics:** View total, open, and resolved ticket counts.
- **Search Functionality:** Search tickets by title or ticket ID.
- **Filtering:** Filter tickets by status and priority.
- **Priority Indicators:** Visually distinguish High, Medium, and Low priority tickets.
- **Date Tracking:** Record and display ticket submission dates.
- **Local Storage:** Save tickets in the browser so they remain available after refreshing the page.
- **Responsive Design:** Adapt the interface to different screen sizes.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/onyxPeter/it-support-ticket-management-system.git
   ```

2. Open the project folder.
3. Open `index.html` in your web browser.

No additional dependencies or installations are required.
